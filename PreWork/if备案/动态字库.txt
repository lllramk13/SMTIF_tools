GPU端口         名称        说明
1F801810h-写    GP0         发送 GP0 命令/数据包（渲染和 VRAM 访问）
1F801814h-写    GP1         发送 GP1 命令（显示控制和 DMA 控制）
1F801810h-读    GPUREAD     接收对 GP0(C0h) 和 GP1(10h) 命令的响应
1F801814h-读    GPUSTAT     接收 GPU 状态寄存器
    GP1 显示控制命令通过向端口 1F801814h 写入 8 位命令号（最高有效位）和 24 位参数（最低有效位）来发送。与 GP0 命令不同，GP1 命令直接传递给 GPU（即即使 FIFO 已满也可以发送）。
    GP1(04h) - DMA 方向 / 数据请求
        0-1  DMA 方向 (0=关闭, 1=FIFO, 2=CPU到GP0, 3=GPUREAD到CPU) ;GPUSTAT.29-30
        2-23 未使用（零）

DMA 寄存器摘要
    1F80108xh DMA0 通道 0 MDECin (内存至 MDEC)
    1F80109xh DMA1 通道 1 MDECout (MDEC 至内存)
    1F8010Axh DMA2 通道 2 GPU (列表 + 图像数据)
    1F8010Bxh DMA3 通道 3 CDROM (CDROM 至内存)
    1F8010Cxh DMA4 通道 4 SPU
    1F8010Dxh DMA5 通道 5 PIO (扩展端口)
    1F8010Exh DMA6 通道 6 OTC (反向清除 OT) (GPU 相关)
    1F8010F0h DPCR - DMA 控制寄存器
    1F8010F4h DICR - DMA 中断寄存器
    这些端口控制 CPU 端的 DMA。在大多数情况下，您还需要在远端（例如，对于 DMA2 是在 GPU 端）初始化一个地址（以及传输方向、启用传输等）。

        1F801080h+N*10h - D#_MADR - DMA 基地址 (通道 0..6) (读/写)
            0-23 DMA 开始读取/写入的内存地址
            24-31 未使用 (始终为零)
        在同步模式 0 下，硬件不会更新 MADR 寄存器（即使在传输期间和传输之后，它也将包含起始地址）（除非启用了 Chopping（切分），在这种情况下它会更新 MADR，当被更高优先级的 DMA 通道中断时可能也会发生这种情况）。
        在同步模式 1 和同步模式 2 下，硬件会更新 MADR（它将包含当前传输块的起始地址；在传输结束时，在同步模式 1 下它将保存结束地址，在同步模式 2 下它将保存结束标记）。
        注意：地址位 0-1 是可写的，但任何更新的当前/结束地址都是字对齐的，位 0-1 强制为零。
        当地址计数器从 000000h 向下计数到 FFFFFCh 时会发生回绕，导致回绕后的字不会被写入 RAM（因为 FFFFFCh 超出了默认的 8 MB 主 RAM 区域）。

        1F801084h+N*10h - D#_BCR - DMA 块控制 (通道 0..6) (读/写)
        对于同步模式 0 (即用于 OTC 和 CDROM):
            0-15 BC 字数 (0001h..FFFFh) (或 0=10000h 字)
            16-31 0 未使用 (通常 OTC 为 0，CDROM 为 1 ("一个块"))
        对于同步模式 1 (即用于 MDEC、SPU 和 GPU-vram-数据):
            0-15 BS 块大小 (字数) ; GPU/SPU 最大 10h，MDEC 最大 20h
            16-31 BA 块数量 ; 即 总长度 = BS*BA 字
        对于同步模式 2 (即用于 GPU-命令-列表):
            0-31 0 未使用 (应为零) (传输在列表中的 END-CODE 处结束)
            BC/BS/BA 的范围可以是 0001h..FFFFh (或 0=10000h)。对于 BS，注意不要将块大小设置得大于相应单元的缓冲区所能容纳的大小。(GPU 和 SPU 都有一个 16 字的缓冲区)。更大的块大小意味着更快的传输。
        同步模式 1 将 BA 递减至零，启用 Chopping 的同步模式 0 将 BC 递减至零 (除了这两种情况，D#_BCR 在传输期间/之后不会改变)。

        1F801088h+N*10h - D#_CHCR - DMA 通道控制 (通道 0..6) (读/写)
            0 传输方向 (0=设备到 RAM, 1=RAM 到设备)
            1 每步 MADR 增量 (0=+4, 1=-4)
            2-7 未使用
            8 当为 1 时:
                -Burst 模式: 启用 "chopping" (CPU 周期窃取)
                -Slice 模式: 导致 DMA 挂起
                -Linked-list 模式: 在数据之前传输头?
            9-10 传输模式 (SyncMode)
                0=Burst (在 DREQ 首次置位后立即传输所有数据)
                1=Slice (将数据分割成块，每当 DREQ 置位时传输下一个块)
                2=Linked-list 模式
                3=保留
            11-15 未使用
            16-18 Chopping DMA 窗口大小 (1 << N 字)
            19 未使用
            20-22 Chopping CPU 窗口大小 (1 << N 周期)
            23 未使用
            24 开始传输 (0=停止/完成, 1=开始/繁忙)
            25-27 未使用
            28 强制开始传输，无需等待 DREQ
            29 在强制突发模式下，设置时暂停传输。
               在其他模式下，阻止位 28 在一个切片传输后被清除。
               当传输由 DREQ 引起时无效。
            30 执行总线监听 (允许 DMA 从 -不存在的- 缓存读取?)
            31 未使用
            位 28 在传输开始时自动清除，此位仅在同步模式 0 下需要设置（在其他同步模式下设置它会强制第一个块在没有 DREQ 的情况下立即传输，这是不希望的）。
            位 24 在传输完成时自动清除，对于所有同步模式，启动传输时必须始终设置此位。
            对于 DMA6/OTC 有一些限制，D6_CHCR 只有三个可读/写位：24,28,30。所有其他位都是只读的：位 1 始终为 1 (增量=-4)，其他位始终为 0。
